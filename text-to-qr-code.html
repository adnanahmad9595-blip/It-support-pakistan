How to use this tool

  1. Type or paste your text or link.
  2. Press Create QR Code.
  3. Download the PNG and test it with your phone camera.

Tips

  • Short text makes a simpler code that scans more easily. Under 300 characters is best.
  • Text in any language works, including Arabic, Hindi and Chinese.
  • Print the code at least 2 cm wide so cameras read it easily.
  • Check a finished code with the QR Code Reader before you print it.

Questions

How much text can I use?

Up to 1,000 characters here. Shorter is easier to scan.

Is there a minimum?

No. Even a single word works.

Is my file uploaded to a server?

No. Everything runs in your browser, so your files stay on your device.

Do I need to log in?

No. There is no account, login or daily limit.
