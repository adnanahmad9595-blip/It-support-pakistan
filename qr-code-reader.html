What is a QR code reader?

A QR code reader, also called a QR code scanner or decoder, turns the black-and-white squares of a QR code back into the information stored inside it. That information is usually a web link, but it can also be plain text, a phone number, an email address, a contact card or Wi-Fi details. This page reads QR codes from images such as screenshots and photos saved on your device. To scan a code live with your camera, use the live QR code scanner.

How to read a QR code from an image

  1. Press Select QR Image and choose a picture that contains a QR code. A screenshot, a photo of a poster or an image you received on WhatsApp or email all work.
  2. Press Decode QR to Text.
  3. The text or link inside the code appears in the box. Press Copy Text to copy it.

The image is read inside your browser, so it is not uploaded to our server.

What can be inside a QR code?

  • A web link: the most common case, such as a shop, menu, form or social profile.
  • Plain text: a message, a code or a serial number.
  • A phone number, SMS or email: text that opens the dialer or mail app when scanned with a phone camera.
  • Wi-Fi details: usually written like WIFI:S:NetworkName;T:WPA;P:password;;, which shows the network name and password.
  • A contact card: a name, number and email in a standard format.

Reading the code as text first shows you the exact content, so you can decide what to do with it.

Why read a QR code before you open it?

A QR code hides its destination. Scammers know this and stick fake codes over real ones on parking meters, posters and parcel notices, or send them in emails. This is sometimes called QR phishing. If your phone opens the link instantly, you only find out where it leads after the page has loaded.

Reading the code here first lets you check the address before you visit it:

  • Look at the domain name. Does it match the company you expect?
  • Be careful with shortened links, misspelled names and addresses full of random letters.
  • Be suspicious of codes that ask for a payment, a password or urgent action.
  • Never enter card details or passwords on a page you reached from a code you do not trust.

Why is my QR code not detected?

  • The image is blurry or too small. Use a sharper, larger picture.
  • The code is cut off. The whole code, including the empty border around it, should be visible.
  • Glare or a very dark photo. Take the picture again in even light.
  • A crooked or curved surface. Photograph the code straight on.
  • Too much background. Crop the picture so the QR code fills most of it.
  • It is not a QR code. Barcodes on products are a different type and need a barcode reader.

QR code reader or QR code scanner?

The two names mean the same thing. This page reads codes from image files. To scan a printed code with your camera, use the live QR code scanner. Both show the content as text and never open links by themselves.

Questions

How do I read a QR code from a screenshot?

Save the screenshot, select it with the Select QR Image button, and press Decode QR to Text.

Can I read a QR code from a photo on my phone?

Yes. Choose the photo from your gallery. Make sure the whole code is sharp and fully visible.

Does the QR code reader open the link for me?

No. It only shows the text. You decide whether to open the link after checking it.

Is my image uploaded to a server?

No. The code is decoded in your browser on your device.

Which image formats work?

Common formats such as JPG, PNG and WebP work. If your file does not load, convert it with the PNG to JPG or WebP to JPG tool.

Can I read more than one QR code at once?

This tool reads one code at a time. If an image has several codes, crop it so only one is visible.

Why does it say no QR code was found?

The image is probably too blurry, too small or cropped. Use a clearer picture of the whole code.

Is this QR code reader free?

Yes, with no signup and no limit.
