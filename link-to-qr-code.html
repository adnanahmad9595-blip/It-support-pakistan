How to use this tool

  1. Type or paste your text or link.
  2. Press Create QR Code.
  3. Download the PNG and test it with your phone camera.

Tips

  • Start the link with https:// so phones recognise it as a web address.
  • Use a short link for a simpler code that scans faster.
  • Test the code with your own phone before you print it.
  • Want to check what an existing QR code says? Use the QR Code Reader.

Questions

Does the QR code expire?

No. It simply holds your link, so it works as long as the link works.

Can I use it for a WhatsApp or Maps link?

Yes. Any link works the same way.

Is my file uploaded to a server?

No. Everything runs in your browser, so your files stay on your device.

Do I need to log in?

No. There is no account, login or daily limit.
